=============================== ALGORITHM ===============================

ASSERT = must hold. On failure repair state, then continue. Checked against
         CALLS MADE, never against your impression of the run.
DO     = act exactly as written.
YOURS  = your judgement. The algorithm fixes the shape, not the content.

UNIT   = the thing the run ranges over, fixed once at 0.3:
           MULTI-REPO  (GATE ROSTER lists >1 repo) -> UNIT = one repository
           SINGLE-REPO (GATE ROSTER lists 1 repo)  -> UNIT = one area:
                        apps/*, packages/*, or a feature folder under them
         Areas in a monorepo play the part repositories play across them:
         different maintainers, different registers, and code in one routinely
         does not import code in another. Every rule below reads UNIT.
SCOPE  = the argument that confines a call to one UNIT:
           MULTI-REPO  -> knowledgeId = <that repo's id, from roll_call>
           SINGLE-REPO -> pathContains = <that area, verbatim from RETAINED[]>
TRACE  = DO collateral_damage(relativePath = <a file>, SCOPE, commitHash,
              lenses INCLUDING dependencies)
         It walks that file's edges: what it imports, what imports it, the types
         it declares, its call sites. Searching finds files that share your
         WORDS; tracing finds files that share its WIRING.

RETAINED[] { unit, verdict, relevance, depth }          fixed at 0.3 / 0.3s
DROPPED[]  { unit, verdict }
SEARCHED   { (ob.id, unit) } — entered only by 3.2, with THAT ob's phrase
SEEN       every path any call returned. Append, never prune.
TRACED     { unit, relativePath, lenses, rows } — one entry per TRACE CALL you
           issued and read. Nothing else enters TRACED: not a row in another
           trace's output, not a lens naming the unit, not a belief that the
           unit is covered. A unit you cannot name a traced path for is
           UNTRACED — write it down as untraced.
CONFIRMED  { path, role VIOLATOR|OWNER|EVIDENCE, why } — files READ at 5.1
RULED_OUT  files READ and excluded against verbatim source. Not reading ≠ ruling.
CANDIDATES SEEN − CONFIRMED − RULED_OUT, minus paths under DROPPED units.
NAMES      symbols from results, pending 4.1.

INV-1  every CONFIRMED path is emitted. No filter, no "already covered".
INV-2  CLOSED records a fact; it never exits a loop or removes work.
INV-3  reading sets ORDER, never LENGTH. Unread ≠ dropped.
